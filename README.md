# Amazon Fine Food Reviews — Sentiment Analysis

**CSE 3521: Survey of Artificial Intelligence I — Autumn 2026 Group Project**

## Description

This project uses the [Amazon Fine Food Reviews](https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews) dataset to classify reviews as positive or negative. The Streamlit app compares Naive Bayes and logistic regression with bag-of-words and TF-IDF features. It also shows test-set results and a summary of the data and preprocessing.

### Planned approach

- **Features:** Bag of Words and TF-IDF
- **Classical models:** Naive Bayes, Logistic Regression
- **Deep model:** Feedforward Neural Network
- **App:** Streamlit web app with live predictions from multiple models

## Data

Download `Reviews.csv` from Kaggle and sample 50,000 rows with `random_state = 42`. Data files are not committed due to size.

## Reproducing the pipeline

1. Create a `data/` folder in the repository root if it does not already exist. Download `Reviews.csv` from [Kaggle](https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews) and place it in `data/Reviews.csv`.

2. Install the dependencies from the repository root:

```bash
python -m pip install -r requirements.txt
```

3. Run the data preparation and model-training scripts from inside `notebooks/`:

```bash
cd notebooks
python make_sample.py
python preprocess.py
python feature_engineering.py
python train_naive_bayes.py
python train_logistic_regression.py
cd ..
```

Feature engineering creates the shared training/test splits, fitted vectorizers, and feature matrices in `notebooks/outputs/`. The training scripts save the Naive Bayes and logistic-regression models in `models/`.

See [notebooks/README_DATA_ENGINEERING.md](notebooks/README_DATA_ENGINEERING.md) for preprocessing decisions and output files.

## Running the Streamlit app

After preparing the data and training both model families, run this command from the repository root:

```bash
python -m streamlit run app.py
```

For WSL, use the following command to avoid automatic browser-launch errors:

```bash
python -m streamlit run app.py --server.headless true
```

Open the Local URL printed in the terminal, usually `http://localhost:8501`. Keep the terminal running while using the app. Press `Ctrl+C` in that terminal to stop the server.

### App tabs

- **Review analysis:** Enter a review or select an illustrative example, choose TF-IDF or bag-of-words features, and click **Analyze review** to compare predictions from Naive Bayes and logistic regression.
- **Test performance:** Compare the four model/feature configurations on the saved test split. View accuracy, macro F1, negative-class recall and F1, confusion matrices, and class-specific results.
- **Dataset:** View the saved training/test counts, class distribution, label definitions, and preprocessing steps.

The app requires the four trained model files in `models/` and the fitted vectorizers in `notebooks/outputs/`. The performance and dataset tabs also use the saved split CSVs and test feature matrices. These files are generated by the pipeline above.

Ratings of 4–5 stars are labeled positive, ratings of 1–2 stars are labeled negative, and 3-star reviews are excluded. Displayed probabilities are model estimates for an individual review; test-set performance is reported separately.
